📘 What Will You Install?
Today, we'll install two important tools:

1️⃣ Python
2️⃣ Visual Studio Code (VS Code)
Think of them like this:

🐍 Python is the engine.

💻 VS Code is the workspace where you'll write your code.
Without Python, your computer won't understand Python programs.
Without VS Code, writing code becomes much harder.
Together, they make programming simple and enjoyable.

📘 Step 1: Install Python

Python is the programming language we'll use throughout this course.
Follow these simple steps:
✅ Visit the official Python website.
✅ Download the latest version for your operating system (Windows, macOS, or Linux).
✅ Open the downloaded installer.

⭐ VERY IMPORTANT ⭐

During installation, you'll see a small checkbox that says:
☑ Add Python to PATH
Make sure you tick this box before clicking "Install Now."
Many beginners skip this step and later wonder why Python isn't working.
Adding Python to PATH allows your computer to recognize Python from anywhere,

including the Command Prompt or Terminal.
Finally...

Click Install Now and wait for the installation to finish.
Congratulations! 🎉
You now have Python installed.

📘 Step 2: Install VS Code

Now it's time to install your code editor.
What is VS Code?
VS Code (Visual Studio Code) is a free application where programmers write and manage their code.
Think of it as Microsoft Word...
But instead of typing letters and documents, you'll use it to write computer programs.

After installing VS Code:

✅ Open it.
✅ Go to the Extensions section.
✅ Search for Python.
✅ Install the official Python extension.

This extension gives you useful features like syntax highlighting, code suggestions, debugging, and the ability to run Python programs more easily.

Restart VS Code if prompted.
You're almost ready!

📘 Step 3: Verify Your Python Installation

Now let's confirm that everything was installed correctly.
Open:
- Command Prompt (Windows)
- Terminal (macOS or Linux)
Type:
python --version
Then press Enter.
If that doesn't work, try:
python3 --version
If you see something like:
Python 3.13.7

🎉 Congratulations!

Your installation was successful.
You're officially ready to start programming.
